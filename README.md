## 🎯 Overview

This portfolio website highlights my work as an undergraduate researcher specializing in:

- **Block Copolymer Self-Assembly** – High-throughput thin film fabrication and characterization
- **Organic Solar Cells** – Fabrication and thermal stability analysis of polymer-based photovoltaics
- **Laboratory Automation** – End-to-end robotic orchestration for autonomous materials research
- **3D Printing Engineering** – Custom lab equipment and infrastructure design

## 🚀 Getting Started

### Prerequisites

No build tools required! This is a pure HTML/CSS/JS project.

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/S8bin-dev/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Open in browser**
   ```bash
   # Using Python's built-in server
   python -m http.server 8000
   
   # Or simply open index.html directly in your browser
   ```

3. **View at** `http://localhost:8000`
